# General Instructions

## Maintain Project Knowledge
Whenever you make any architectural changes, add new features, fix significant bugs, or modify the codebase in `omnichannel-platform`, you MUST update the `PROJECT_KNOWLEDGE.md` file located at the root of the project.
Append the current date, details of the changes you made, and any new context to the "Change Log & Notes" section. This ensures seamless handoffs between AI sessions.
